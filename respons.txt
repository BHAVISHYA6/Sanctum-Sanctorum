- limit defaults to 20 and is restricted to 1 through 100.
- offset defaults to 0 and cannot be negative.
- total is calculated before limit and offset.
- Book response pagination fields are items, total, limit, and offset.
- Mixed-case ordering is database-dependent as allowed by the spec.

- Items preserve submitted order.
- POST /orders returns 201 with pending status.
- Empty items return 422.
- Quantity below 1 returns 422.
- Duplicate book ids return 422.

- Missing book returns 404.
- Restricted access is checked before stock failure.
- Insufficient stock returns 409.
- All stock checks happen before stock mutation.
- Failed orders do not create an order or partially change stock.

- Tier discounts are 0%, 5%, 10%, and 15%.
- Bulk discount adds 5% at total quantity 10 or more.
- Discount cents use floor division as required.
- GET /orders/{id} returns the order or 404.
- Paying changes pending to paid and leaves stock unchanged.
- Paying any other status returns 409.
- Cancelling changes pending to cancelled and restores stock.
- Cancelling any other status returns 409.
- Related stock/order changes are committed together.

6. Loans: PASS
- LoanOut contains the required fields.
- Loan status is computed at read time.
- Returned status takes priority over overdue status.
- Exactly due_at is active, not overdue, and has no late fee.
- Tier loan limits are apprentice 1, adept 3, master 5, supreme unlimited.
- POST /loans returns 201.
- Member existence is checked before book existence.
- Missing member/book return 404.
- Restricted books require master or supreme.
- Existing overdue loans block new borrowing.
- An active duplicate book loan is rejected.
- Tier loan limits are enforced.
- Zero stock is rejected.
- Successful borrowing sets now, now + 14 days, null returned_at, and zero fee.
- Borrowing decrements stock.
- GET /loans/{id} returns the computed loan or 404.
- Returning a missing loan returns 404.
- Returning twice returns 409.
- Returning sets returned_at to now and restores stock.
- Late days use ceiling, so every partial day counts.
- Late fees are 25 cents per started late day.
- Late fees are capped at the book price at return time.
- Member loan listing supports active, overdue, and returned computed filters.
- Invalid loan status values return 422.
- Member loan results are ordered by id ascending.
